# Breast Cancer Prediction Web App
Developed by: Abitha

Live Web Application: https://breast-cancer-app-jagodrjytfcezrkqqtaofi.streamlit.app

## About the Project
This is a Machine Learning web application built with Python, Streamlit, and Scikit-Learn. It predicts breast cancer diagnosis (Benign or Malignant) based on clinical input features and tracks patient prediction history in real-time.
